# Our Project

这里保存 ModelRouter 项目自身的研究内容：

- `literature/`：文献表、调研报告和证据分册；
- `data/`：来源数据、清洗数据和统计汇总；
- `papers/`：纳入研究材料的论文文本；
- `planning/`：数据融合和实现规划。

数据文件已移除渠道凭据、提示词、完整回复和其他敏感字段。成本单位不同的来源仍分开记录，不能直接相加。
## 当前方案与三份持续维护文档

- [Planning Memory](planning/PLANNING_MEMORY.md)：跨轮次研究决策、Agent 分工、任务交接和更新纪律。
- [Project Status](planning/PROJECT_STATUS.md)：E0 审计事实、现有条件、数据可用性、实验阶段、阻塞与验收。
- [Research Overview](planning/RESEARCH_OVERVIEW.md)：最新 Model × Effort 状态感知路由问题、Kev-4B 方法、相关工作、实验协议。

`planning/IMPLEMENTATION_RESEARCH.md` 与 `literature/report.md` 为早期 admission-only 成本预测研究，保留作历史参考和对照，不再覆盖最新研究决策。公开文件不记录私人主机与原始会话。
