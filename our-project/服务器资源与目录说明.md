## 4. 跨机协同与轻量同步方案 (方案 A)

鉴于服务器未配置 GitHub 仓库直连推送权限（且大数据集绝不宜入库 Git），项目严格采用**方案 A**运作：

1. **计算与存储归口服务器**:
   - 原始大文件、清洗后的大型 JSONL/Parquet 以及未来 Kev-4B 训练权重全量留存于服务器 NVMe 硬盘；
   - 绝不通过 Git 跟踪或提交体积超过 100 MB 的数据文件（根目录 `.gitignore` 已配置 `data/` 忽略）。
2. **本地与 GitHub 主干对齐**:
   - 本地主机通过 SSH/SCP 定期拉取**轻量清洗报告 Markdown**与**各领域 50 条样本数据预览 JSON**；
   - 本地 Git 工作区仅维护 Python 代码、研究文档与轻量预览文件，直接推送到 GitHub `main` 分支；
   - Planning Agent 与论文编写可完全基于本地同步的实测报告与标准样本展开，无需跨网拉取大文件。
