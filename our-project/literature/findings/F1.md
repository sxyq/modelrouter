# F1: 查询级 LLM routing 主线原文核实

## Findings

### [1] RouteLLM 是严格的二元查询级路由：每条 query 只调用一个 LLM，预测强模型胜出概率后由成本阈值 α 决策
- quote: "An ideal LLM router must (1) optimize response quality while invoking a single LLM per query, minimizing cost and latency as compared to multi-LLM approaches" / "R^α(q) = M_weak if P(win_s | q) < α, M_strong if P(win_s | q) ≥ α"
- url: https://arxiv.org/html/2406.18665v4
- source_type: primary
- published: 2024-06-26 (v1); 2025-02-23 (v4)
- confidence: high

### [2] RouteLLM 用 Chatbot Arena 人类偏好训练 win-probability 路由器；成本指标是“调到强模型的比例”而非任务总花费；主结果为 MT Bench / MMLU / GSM8K 上 CPT 与 APGR
- quote: "c(M_{R^α}) = (1/|Q|) Σ_q 1{R^α(q)=M_strong}" / "we can reduce costs by over 2 times without sacrificing response quality"
- url: https://arxiv.org/html/2406.18665v4
- source_type: primary
- published: 2024-06-26 / rev. 2025-02-23
- confidence: high

### [3] RouteLLM 模型池固定为 strong/weak 两类（实验 GPT-4 vs Mixtral-8x7B），并展示测试时更换模型对仍可迁移；不建模调用次数/轨迹/多步 Agent
- quote: "we focus on routing between two classes of models: (1) strong models … (2) weak models" / "maintaining performance even when routing between LLMs not included in training"
- url: https://arxiv.org/html/2406.18665v4
- source_type: primary
- published: 2024-06 / 2025-02
- confidence: high

### [4] Hybrid LLM（ICLR 2024）用 DeBERTa 路由器预测小模型相对大模型的质量差（BART score），测试时可调质量阈值；最多减少约 40% 大模型调用且质量不降
- quote: "Our approach uses a router that assigns queries to the small or large model based on the predicted query difficulty and the desired quality level. … make up to 40% fewer calls to the large model, with no drop in response quality."
- url: https://arxiv.org/abs/2404.14618
- source_type: primary
- published: 2024-04-22 (ICLR 2024 main)
- confidence: high

### [5] Hybrid LLM 明确保证每 query 单次 LLM 调用，并把成本优势定义为“路由到小模型的 query 百分比”，不是美元总成本或 Agent 任务预算
- quote: "we always route each query to a single LLM at inference time as opposed to using an ensemble … or a cascade" / "we define cost advantage as the percentage of queries routed to the smaller model"
- url: https://arxiv.org/html/2404.14618v1
- source_type: primary
- published: 2024-04-22
- confidence: high

### [6] Hybrid LLM 的路由信号是查询文本上的二元分类（是否小模型不差于大模型），训练标签来自 MixInstruct 20k 指令 + BART 质量分；概率路由器用每模型采样 10 次估计软标签
- quote: "y_i^{prob} := Pr[H(x_i) ≥ 0]" / "we estimate expectation by sampling 10 responses from each model"
- url: https://arxiv.org/html/2404.14618v1
- source_type: primary
- published: 2024-04-22
- confidence: high

### [7] FrugalGPT（2023-05）是 LLM cascade：串行调用多个 API，用 generation scoring function 判断可靠性并在阈值处停止；不是预训练路由器，但显式面向 API 花费
- quote: "The key components of LLM cascade consist of two elements: (i) a generation scoring function and (ii) an LLM router. The generation scoring function, denoted by g(·,·): Q×A ↦ [0,1]"
- url: https://arxiv.org/html/2305.05176v1
- source_type: primary
- published: 2023-05-09
- confidence: high

### [8] FrugalGPT 论文声称可在匹配 GPT-4 精度时最多降本 98%，或同成本下超 GPT-4 约 4%；策略空间含 prompt adaptation、LLM approximation、LLM cascade
- quote: "FrugalGPT can match the performance of the best individual LLM (e.g., GPT-4) with up to 98% cost reduction or improve the accuracy over GPT-4 by 4% with the same cost."
- url: https://arxiv.org/abs/2305.05176
- source_type: primary
- published: 2023-05-09
- confidence: high

### [9] AutoMix（NeurIPS 2024）在单 query 上先由小模型生成、再 few-shot 自验证、再按置信度升级到更大模型；POMDP 路由器奖励为 R = P − λ·C，50 条样本即可训练，声称可降本 >50%
- quote: "it employs a POMDP based router that can effectively select an appropriately sized model, based on answer confidence. … reducing computational cost by over 50% for comparable performance."
- url: https://arxiv.org/abs/2310.12963
- source_type: primary
- published: 2023-10-19 (v1); NeurIPS 2024; v5 2025-01-19
- confidence: high

### [10] AutoMix 引入 ibc（Incremental Benefit per Cost）度量相对 SLM→LLM 线段的性价比，并明确目标含“不可解问题不应再升级到任何更大 LM 以省钱”；仍是 query 级混合，非长程 Agent 轨迹
- quote: "unsolvable queries that no model can solve should not be routed to any LM, thereby saving costs" / "ibc_M = (P_M − P_SLM)/(C_M − C_SLM)"
- url: https://arxiv.org/html/2310.12963v5
- source_type: primary
- published: 2023-10 / rev. 2025-01
- confidence: high

### [11] RouterBench（Martian）发布 405,467 条预生成推理结果（11 模型 × 8 数据集），用非递减凸包与 AIQ（平均质量提升）比较路由器；发现同等性能下美元成本可差 2–5×
- quote: "a comprehensive dataset comprising over 405k inference outcomes" / "the monetary costs of LLM services can routinely vary by factors of 2-5× for comparable levels of performance"
- url: https://arxiv.org/html/2403.12031v2
- source_type: primary
- published: 2024-03-18 (v2 2024-03-28)
- confidence: high

### [12] RouterBench 将路由二分：non-predictive（如 FrugalGPT 顺序 cascade 判分）vs predictive（KNN/MLP 预测各模型性能再选）；其 predictive 路由器打分含 λ·P − cost，成本近似用 per-token 价格，不是 Agent 任务总成本
- quote: "Routing can be classified into two categories, non-predictive routing and predictive routing." / "performance score_ij = λ · P_ij − cost_j"
- url: https://arxiv.org/html/2403.12031v2
- source_type: primary
- published: 2024-03
- confidence: high

### [13] Zooter（2311.08692）用现成 reward model 从训练 query 蒸馏路由标签，把每个 query 分配给有专长的 LLM；RouteLLM 将其与 Hybrid-LLM 并列为查询级路由近邻，而非 Agent 轨迹级成本规划
- quote: "We propose Zooter, a reward-guided routing method distilling rewards on training queries to train a routing function, which can precisely distribute each query to the LLM with expertise about it."
- url: https://arxiv.org/abs/2311.08692
- source_type: primary
- published: 2023-11-15
- confidence: high

### [14] 主线共同边界（跨文原文可对齐）：路由粒度=单条用户 query；路由时信息=查询文本（及 AutoMix/FrugalGPT 的初步答案/验证分）；成功概率≈win/quality-gap/verifier confidence；成本=强模型调用比例、API 单 query 花费或 cascade 次数；均未见“长程 Agent 任务级总成本/多步轨迹预算”作为优化对象
- quote: RouteLLM: "invoking a single LLM per query"；Hybrid LLM: "always route each query to a single LLM"；AutoMix: "self-verification … selective routing"；RouterBench: "R_θ(x) ↦ LLM_i"
- url: https://arxiv.org/html/2406.18665v4
- source_type: primary
- published: 2023–2025
- confidence: high
- note: 此为对已抓取原文的对照综合，不是某一单篇的 abstract 摘抄；各子句均可在对应 finding 的 quote 中复核。
