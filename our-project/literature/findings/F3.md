# F3: 成本反转与预算/推理档位路由

## Findings

### [1] FrugalGPT（LLM cascade）可把匹配最佳单模型的成本压到原来的 1/50（HEADLINES 上98% 降幅），核心是“廉价模型优先 + 按分数阈值升级”
- quote: "FrugalGPT can match the performance of the best individual LLM (e.g. GPT-4) with up to 98% cost reduction or improve the accuracy over GPT-4 by 4% with the same cost." / Table 3: "HEADLINES GPT-4 33.1 0.6 98.3%"
- url: https://arxiv.org/abs/2305.05176
- source_type: primary
- published: 2023-05-09
- confidence: high
- 粒度：单次 query；可用信息：商业 API 混合定价（GPT-4/GPT-3/J1 等，价差可达 2 个数量级）；是否预测成功/调用数：学习 scorer 决定是否升级（隐式预测“是否还行”），不显式建模任务成功概率；是否任务总成本：单查询累计成本（数据集级总花费），非多步 agent 整任务；模型池：多个商业 API；指标：准确率–成本；结论：cascade 可在同准确率下大幅降本；与“任务级成本反转”关系：为“便宜模型优先 + 升级”提供最早系统证据，但未报告 $/success 排序反转率；局限：2023 价格、非 agent 长程任务。论文写明：98%/4% 成本结论；“排序反转”需从 Table 3 的 cost-to-match 推断。

### [2] RouteLLM 用偏好数据在强/弱两模型间单次路由，达到约 95% GPT-4 质量时最高可省 ~85% 成本（MT Bench）
- quote: "our routers achieve cost savings of up to 3.66x, demonstrating that routing can significantly reduce cost while maintaining response quality." / CPT(50%) for 95% GPT-4 quality: MT Bench 3.66, MMLU 1.41, GSM8K 1.49
- url: https://arxiv.org/abs/2406.18665
- source_type: primary
- published: 2024-06-26 (v4 2025-02-23)
- confidence: high
- 粒度：单次 query；可用信息：强/弱对（GPT-4 Turbo vs Mixtral-8x7B 等）、价差可达 50×（Haiku vs Opus 举例）；是否预测成功：BERT/因果 LLM/矩阵分解预测哪边更好（偏好胜负，非任务成功率）；是否任务总成本：请求级期望成本（CPT = 成本节省比），非整 agent 轨迹；模型池：两模型；指标：PGR/APGR/CPT；结论：路由在保持强模型质量分数时显著降本；与成本反转：建立成本–质量 Pareto，未主张“更贵模型 $/success 更低”；局限：单轮对话基准。论文写明：3.66x/2x 等。

### [3] Hybrid LLM：路由器可把 20–40% 查询交给小模型而质量几乎不掉；约 20% 查询上 Llama-2-13B 质量优于 GPT-3.5-turbo（单例质量反转素材）
- quote: "our router can make 22% fewer calls to GPT-3.5-turbo (cost advantage) with 1% drop in response quality (BART score)." / "Llama-2 (13b) outperforms GPT-3.5-turbo on around 20% examples"
- url: https://arxiv.org/abs/2404.14618
- source_type: primary
- published: 2024-04-22 (ICLR 2024)
- confidence: high
- 粒度：单 query；可用信息：小/大模型对、desired quality level 可调；是否预测成功：按预测难度路由，不预测任务成功；是否任务总成本：cost advantage = 交给小模型的比例；模型池：两模型；指标：BART score + cost advantage；结论：少打大模型可保质量；与成本反转：提供“便宜模型在部分实例上更强”的直接证据（$/$/success 反转的必要不充分条件）；局限：摘要式 BART 指标。论文写明：22%/20% 等。

### [4] Route-to-Reason（WWW 2026）在“模型 × 推理策略”上联合选择，并训练 token 长度回归头作成本代理：相对最强单模型 QwQ-32B 准确率 +2.5pp 且输出 token 减 60%+
- quote: "RTR achieves an optimal trade-off between accuracy and computational efficiency among all baselines, achieving higher accuracy than the best single model while reducing token usage by over 60%."
- url: https://arxiv.org/abs/2505.19435
- source_type: primary
- published: 2025-05-26; journal: WWW 2026
- confidence: high
- 粒度：单 query 的 (model, strategy) 对；可用信息：7 个开源模型 × 4 种推理策略；是否预测成功：MLP 预测 performance score；是否预测成本：是——预测生成 token 数 l̂ 作为 inference 成本代理（非美元、非整任务轨迹）；模型池：开源推理/非推理模型；指标：accuracy、avg answer tokens、λ 曲线；结论：联合选择可同时优于最佳单一模型在准确率与 token 上；与成本反转：最接近的学术工作——“更大/最强配置不划算”的 token 级反转；局限：策略是 CoT 类而非 OpenAI `reasoning.effort` 档位；无 $/success、无多步 agent。论文写明：60% token、+2.5pp；美元化需从 token×单价推断。

### [5] OpenRouter Auto router（2026-08-10）用市场 spend 份额 + 任务分类做模型选择，并公开五基准的准确率与美元成本表（含 ± 仅在准确率上）
- quote: "By referencing the past 7 days of OpenRouter usage... cost_tier parameter accepts low, medium, high, xhigh, or max" / 报告例：SWE-Atlas QnA New Default $297.23 @30.4%±2.0；New Max $1,325.08 @60.7%±1.7；DSQA New Default $276.00 @62.9%±1.6 vs New Max $248.83 @63.0%±1.6
- url: https://openrouter.ai/blog/announcements/introducing-the-new-auto-router/
- source_type: secondary（官方系统博客，一手测量）
- published: 2026-08-10
- confidence: high（数字可信为厂商自测；$ 无 CI）
- 粒度：单 prompt 请求（约 30 类任务分类 + sticky 会话）；可用信息：cost_tier 档位、55T token/周 spend 信号；是否预测成功：市场 spend 份额作代理，不显式预测成功；是否任务总成本：请求级 $，非多步任务；模型池：OpenRouter 全市场；指标：基准准确率 ±、整批 $；结论：默认档以更低 $ 达到接近旧 router 质量；DSQA 上 max 档反而更便宜且准确率持平——从表中数字推断的“档位/成本非单调”；与成本反转：提供生产级请求成本表，但未系统报告单次价 vs $/success 的排序翻转率；局限：自评、模型混合随时间变。

### [6] Together DeepSWE 对比（任务级 $/task）：便宜模型 pass@4 更高、solves/$100 约 30× 于昂贵模型；Pro-first→Sol 级联 83.0% @$3.35/task，高于 Sol 单打 72.7% @$8.37

- url: https://www.together.ai/blog/deepseek-v4-pro-0813-vs-gpt-5-6-sol-on-deepswe-cost-coding-and-routing
- source_type: secondary（厂商评测博客）
- published: unknown（页面含 2025–2026 模型命名；抓取日 2026-09-15）
- confidence: medium-high（一手自测，方法细节有限）
- 粒度：整条 SWE agent rollout（DeepSWE 任务）；可用信息：$/rollout、$/task、solves per $100、pass@1/pass@4、级联升级；是否预测成功：用测试套件作升级信号（事后验证，非事前成功预测）；是否任务总成本：是——任务级美元；模型池：两模型；指标：解决率、$/task、solves/$；结论：更便宜模型在任务级美元效率上压倒昂贵模型；级联同时提升解决率并压低成本；与成本反转：本检索中最直接的“任务级成本反转”证据（solves/$ 与单次价格档位反向）；局限：厂商自评、无置信区间、单一 benchmark。论文写明：上述美元与百分比；“30× solved work per dollar” 为原文表述。

### [7] test-time compute 的 compute-optimal 分配相对 Best-of-N 提升 >4× 效率；FLOPs 对齐下小模型 + 测试时计算可超过 14× 更大模型
- quote: "improve the efficiency of test-time compute scaling by more than 4x compared to a best-of-N baseline" / "test-time compute can be used to outperform a 14x larger model."
- url: https://arxiv.org/abs/2408.03314
- source_type: primary
- published: 2024-08-06
- confidence: high
- 粒度：单 prompt 的推理计算分配；可用信息：难度依赖的有效性；是否预测成功：按 prompt 难度选策略/样本数；是否任务总成本：FLOPs 匹配而非 API $；模型池：预训练小/大模型；指标：准确率 vs 计算；结论：预算应按难度分配；“小 + 多算”可在 FLOPs 上击败“大 + 少算”；与成本反转：为“算力/价格档位与最终效果非单调”提供经典学术证据；局限：非 agent、非美元计价。论文写明：4×、14×。

### [10] Token-Budget-Aware LLM Reasoning（TALE）：按题目复杂度动态设 prompt 内 token 预算，用少量准确率换显著降 token 成本
