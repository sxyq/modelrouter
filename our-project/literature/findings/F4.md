# F4: 事前预测方法与泄露控制

## Findings

### [1] 事前 token 自预测存在明确能力缺口：八个前沿模型在 SWE-bench Verified 上对自身执行前 token 用量只有弱到中等相关（最高约 0.39），且系统性低估真实成本
- quote: "frontier models fail to accurately predict their own token usage (with weak-to-moderate correlations, up to 0.39) and systematically underestimate real token costs." / "We formalize the pre-execution agent token consumption predict tasks in which the agent is asked to predict input and output token usage given all its available tools and the coding environment." / "runs on the same task can differ by up to 30x in total tokens" / "expert-rated task difficulty is a weak predictor of agent token consumption" / "input tokens rather than output tokens driving the overall cost"
- url: https://arxiv.org/abs/2604.22750
- source_type: primary
- published: 2026-04-24 (v2 2026-04-29)
- confidence: high

### [2] BAGEN 把预算预测形式化为“逐区间上下界估计”：强 agent 的预算感知与总体能力相关性仅 r=0.35；早期停机在失败轨迹上省 28–64% token，但区间覆盖率经 SFT+RL 后仍封顶 47%
- quote: "formalize budget-awareness as progressive interval estimation: at each step of a plan, an agent should predict an upper and lower bound on remaining budget, and alert when completion is unlikely." / "strong agents do not necessarily have strong budget-awareness, with correlation r=0.35" / "Early stop saves 28-64% tokens on failed trajectories" / "precise interval calibration remains challenging, with interval coverage capping at 47% after SFT+RL"
- url: https://arxiv.org/abs/2606.00198
- source_type: primary
- published: 2026-05-29
- confidence: high

### [3] EarlyEval 用 LightGBM 在轨迹前缀上训成功/失败分类器提前中止评测：SWE-bench Verified / TerminalBench / Toolathlon 上省 13–26% 步数与至多 44.1% 输入 token（89–97% 预测准确率）——预测目标是最终 resolve，但特征来自执行中前缀而非纯执行前信息
- quote: "trains a pair of LightGBM success and failure classifiers over behavioral, textual, and reference-solution features, and halts an agent run the moment either classifier crosses a calibrated confidence threshold" / "eliminate 13%-26% of agent steps and up to 44.1% input tokens and 29.4% output tokens at 89%-97% prediction accuracy" / "we construct prefixes τ_{:k} … and pair each prefix with the trajectory's final outcome label"
- url: https://arxiv.org/abs/2609.02783
- source_type: primary
- published: 2026-09-02
- confidence: high

### [4] EarlyEval 给出任务级路由器可直接复用的防泄露协议：按 task 切分轨迹池、同一轨迹的全部前缀禁跨侧、leave-one-agent-out、TerminalBench 上再加 no-same-model / no-same-scaffold 两种更严切分，校准只在保留验证折上做
- quote: "To prevent data leakage, we partition the trajectory pool by task into a training fold and a held-out validation fold; all prefixes originating from a given trajectory are strictly restricted to the same side of the split." / "we adopt a leave-one-agent-out protocol that holds out one agent at a time and trains only on the remaining ones" / "evaluate TerminalBench under two complementary settings: (1) no same model in training and (2) no same scaffold in training" / "Within each fold we reserve 15% of the training trajectories as the validation split that drives early stopping and Platt calibration."
- url: https://arxiv.org/html/2609.02783v1
- source_type: primary
- published: 2026-09-02
- confidence: high

### [5] “Doomed from the Start” 用内部隐层线性探针在第一轮交互即预测最终失败，并构造受全局召回率约束的早停级联：90% 召回目标下比最强单门基线多省 1.5–8.8× 计算，TextCraft 上可减 60.2% 生成 token；行为监控一致性弱于隐层探针
- quote: "Lightweight linear probes on internal activations predict eventual task failure from the first interaction round, substantially earlier than agent-monitoring methods based only on observable behavior." / "distribution-free calibrated failure detector at each early interaction round and jointly optimizes per-round recall budgets" / "providing an exact post-selection recall guarantee" / "saving 1.5-8.8 times more compute at a 90% recall target" / "reduce generated tokens by 60.2% on TextCraft"
- url: https://arxiv.org/abs/2607.06503
- source_type: primary
- published: 2026-07-07 (v2 2026-07-16)
- confidence: high

### [6] Bayesian Self-Escalation 把“生成中能否成功”写成带标注轨迹学出的 competence posterior 上的最优停机问题：升级阈值有闭式 myopic 解，插件策略遗憾以 1/√n 衰减；Qwen2.5-Coder 1.5B→7B 的 MBPP 实验中升级前沿在等成本下优于事后路由——是“在线成功概率估计+模型升级”的理论底座，而非纯执行前单点预测
- quote: "an online estimate of the agent's eventual task success whose sufficient statistics are learned from labelled trajectories, not read off raw entropy" / "the deployed plug-in policy's regret decays as a 1/sqrt(n)" / "the escalation frontier dominates post-hoc routing at equal cost, and the cumulative competence belief's discrimination rises over generation" / "a real-model validation on a Qwen2.5-Coder 1.5B->7B code cascade (MBPP, 257 tasks)"
- url: https://arxiv.org/abs/2608.24087
- source_type: primary
- published: 2026-08-25
- confidence: high

### [7] Automata from Agent Traces 把语料折成紧凑 FSM 后，用每状态行为特征做失败预测，held-out AUROC 至 0.94，且在线监测可从部分轨迹给失败跑排序触发早停；FSM 结构在切分间近恒定——轨迹级失败预测可用“跨任务结构特征”而非任务内容记忆
- quote: "collapse an entire trace corpus into a single, compact finite-state machine (FSM)" / "replay held-out data at >=0.997 fitness with near-identical topology across splits" / "per-state behavioral features reach held-out AUROC up to 0.94, and an online monitor ranks failing runs above passing ones from a partial trace, triggering early stopping well before completion"
- url: https://arxiv.org/abs/2608.23670
- source_type: primary
- published: 2026-08-24
- confidence: high

### [8] OUTLETS 证明投机解码草稿模型隐状态可复用作输出长度回归头：在分离式 serving 下让调度优先短请求，短请求 P99 延迟降 34.8%——单次生成级长度预测（服务侧），特征仅来自 prefill/草稿前向，天然执行前
- quote: "latent representations produced by the draft decoder in advanced frameworks (e.g., EAGLE-3) encode signals that are predictive of generation length" / "adds only a lightweight regression head" / "reducing short-request P99 latency by 34.8%"
- url: https://arxiv.org/abs/2609.01068
- source_type: primary
- published: 2026-09-01 (v2 2026-09-10)
- confidence: high

### [9] Robust Length Prediction（ProD）指出输出长度是重尾的“prompt 条件分布”而非标量：用同 prompt 多次独立生成构造中位数/分布目标，纠正单次采样标签的偏差——对“用历史轨迹当标签预测任务 token”的路由器是直接的方法论警示（标注噪声+方差），但场景仍是单次推理而非 agent 任务
- quote: "the same prompt induces a prompt-conditioned output length distribution, not a deterministic scalar, and this distribution is consistent with heavy-tailed behavior" / "cast length prediction as robust estimation from heavy-tailed prompt-conditioned length distributions" / "ProD-M, which uses a median-based target for robust point prediction, and ProD-D, which uses a distributional target"
- url: https://arxiv.org/abs/2604.07931
- source_type: primary
- published: 2026-04-09
- confidence: high

### [10] VeriDispatcher 在 RTL 生成上实现“执行前难度预测→多模型派发”：每个模型一个紧凑分类器，输入是任务描述语义嵌入，难度标签来自基准变体的语法/结构/功能正确性组合分；10 模型上 RTLLM 用 40% 商业调用换来至多 +18% 准确率——是任务描述级（纯执行前）难度路由的最直接先例，但标签由“跑过的结果”离线构造，且仍是单次生成非长程 agent
- quote: "dispatches each RTL task to suitable LLMs based on pre-inference difficulty prediction" / "train a compact classifier over semantic embeddings of task descriptions, using difficulty scores derived from benchmark variants" / "achieves up to 18% accuracy improvement on RTLLM using only 40% of commercial calls" / "on VerilogEval maintains accuracy while reducing commercial usage by 25%"
- url: https://arxiv.org/abs/2511.22749
- source_type: primary
- published: 2025-11-27
- confidence: high

### [11] TRACE-Router 是任务级 contextual bandit 路由：准入时一次性选模型并钉住整条轨迹，只用终局 accuracy+latency 奖励更新，明确“避开显式任务复杂度估计”；tau2-Bench 超延迟匹配插值 7–8 点、Terminal-Bench 比最强单模型 +7.1 点且延迟 −36%。同路线的 PILOT（LinUCB+离线偏好先验+多选背包预算）、BaRP（bandit 反馈训练、测试时可调偏好）、2506.17670（上下文演化下 LinUCB，免未来上下文预测）、2508.09958（子任务管线序贯 bandit，次线性遗憾）共同表明：任务级选模型可用在线 bandit 回报替代事前成功率/token 点预测
- quote: "TRACE-Router assigns each task to a model once at admission using a contextual bandit, pins all subsequent LLM calls to the selected backend, and updates its policy using the task's terminal reward" / "avoiding explicit task-complexity estimation" / "on Terminal-Bench it achieves 7.1 higher accuracy points than the strongest single model baseline with 36% lower latency" / BaRP: "trains under the same partial-feedback restriction as deployment, while supporting preference-tunable inference"
- url: https://arxiv.org/abs/2607.22465
- source_type: primary
- published: 2026-07-24 (TRACE-Router); BaRP 2025-10-08; PILOT 2025-08-28; 2506.17670 2025-06-21; 2508.09958 2025-08-13
- confidence: high

### [12] 泄露影响的定量边界：对 47 个公开模型 + 74 个按已知剂量污染微调模型的四项基准审计显示，污染普遍抬高绝对分但几乎不重排榜单（paraphrase 控制后 rank 相关 0.997，188 个模型×基准组合仅 3 例差异污染被双重佐证）——对路由器评测的推论是：随机同分布切分下“学到的记忆型路由”可能仍给出正确模型排序，真正要防的是差异污染与任务/前缀/模型级交叉泄漏（结合 [4] 的切分协议），而非绝对分虚高本身
- quote: "recast contamination as a violation of anchor-item invariance and measure it through the differential functioning of original versus semantically equivalent paraphrased items" / "the rank correlation between a standard leaderboard and a paraphrase-controlled leaderboard is 0.997" / "only 3 of 188 model-by-benchmark cases showing differential contamination" / "It inflates absolute scores without reordering the leaderboard"
- url: https://arxiv.org/abs/2609.02899
- source_type: primary
- published: 2026-07-05
- confidence: high

## 综合推断（非论文原文）
- 论文写明 vs 推断：以上 [1]–[12] 的具体主张均出自所引原文；以下为在本次检索覆盖范围内的推断。
- 推断：检索覆盖的文献中，未见任何工作在任务开始前同时输出 (P_success, E[调用数], E[输入/输出 token], 重试概率, 质量, 总费用) 的多目标预测头再做“质量约束下最小化预计总费用”的模型×档位联合选择。最接近的分工是：[1]/[2] 预测 token/预算但不选模型；[3]–[7] 预测成败以省算力但不做跨模型比较；[10] 事前难度派发但只在固定小模型池、单次生成；[11] 任务级 bandit 则刻意绕开事前点预测。成功与费用的联合事前预测留给任务级成本感知路由器作为贡献位（有风险：同任务 30× token 方差 [1] 与预算区间覆盖率 47% [2] 表明点估计上限可能很低，宜输出分布/分位数并按 [9] 的重尾标签方法构造训练目标）。
- 推断：对路由器训练数据的防泄露最小集可直接从 [4] 组装：按任务切分 + 前缀不跨侧 + 留一 agent（或留一模型/骨架）+ 独立验证折只用于校准；[12] 提示评测还应做 paraphrase/时间双重审计，防“差异污染”导致的模型选择偏差。

## Suggested follow-ups
- 精读 SWE-Router（2607.00053，已由 F2 覆盖）与 EarlyEval [4] 的特征差：前者 K 步后 continue-or-restart，后者逐步可中止——对照可定义“执行前(k=0) 特征消融”，量化纯事前信息相对前缀信息的 Bayes 差距。
- 查 RouteLLM / RouterBench / Zooter 训练-测试任务重叠与是否公开任务级切分脚本；补 SWE-bench 记忆化文献（如 “SWE-Bench Illusion” 类工作）验证 [12] 结论能否迁移到 agent 轨迹标签。
- 若做联合预测器：按 [9] 对每任务×模型做多次 rollout 估长度分布，按 [2] 输出预算分位区间，按 [5][6] 校准成败概率；评测切分照抄 [4] 的 task-level + leave-one-agent-out + no-same-model。
- 补 1–2 篇 2025 前的输出长度预测奠基作（如基于熵/隐状态的早期方法与 ForeLen 基准的原始定义文），完善 serving 脉络。
