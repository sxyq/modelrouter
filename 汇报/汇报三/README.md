## 实验方案的实事求是原则

- 价格、Effort、缓存与静态模型能力需要同版来源；不画虚构的 Pareto 实测点。
- **主结果必须来自真实 Agent Episode**，包括失败/重试及路由器开销，不以离线 Laya/Kev Accuracy 替代任务级收益。
- 分别控制任务拆分粒度、路由动作、缓存连续性和环境变化；只对真实可执行 Model×Effort 组合比较。
- 受控同状态分支与离线观察性轨迹不可混淆；未支持的动作/指标用“不可评估”，**结果表格模板保持空白**。
- 未获另外授权不启动额外付费 API、Kev、Benchmark 或 GPU 实验；本目录仅为设计及汇报资料。
