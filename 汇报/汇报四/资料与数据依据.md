## 3. 模型、训练、实际可用性

- 正式 Single-Agent：`Harbor → ModelRouterMiniSweAgent → DefaultAgent → 原官方 Verifier`。
- 当前研究池：Luna、GLM-5.3-Flash、Terra，Registry 登记 15 个合法 Model×Native Effort **候选**；登记不代表每档实际返回、身份/费用完整核实。
- 训练：Laya 历史原 38 组中 25 完成两轮；Kev R01–R16 完成；当前 GLM 池两版各完成 17 次参数更新（Laya 736.337 秒，Kev 13,420.549 秒），目前未确定论文最终最优版。
- 新池偏好：1 条五候选有效偏好 + 16 条辅助，不应写成 17 条完全独立的真实联合最优动作。
- AA v7：130 条独立指标；Luna/Terra 六档、GLM 仅 Max 有独立测量，Low/High 缺测；Provider 返回 Effort 及物理权重仍有未知。

## 4. 完整任务与新池近期实证

**Terminal-Bench 2.1.0：89题**（8 canary、24 external_dev、57 final_test），29 题有 Agent 尝试、其中 22 题至少一次 Reward 1/0、7 题已尝试但无 Reward，60 题未尝试；其中 2 题仅有 Oracle。全部 198 条 Harbor 记录 = 187 Agent + 11 Oracle；Agent Reward1/0/缺失 = 67/39/81。跨历史模型池和重复 Trial 的总计**不是当前 V9 Pass 率**。详见[89题逐项清单](../../our-project/results/benchmark/README.md)。

**11-08 GLM 新池近期 49 次尝试**：33 有官方 Reward（21 个1、12个0）、16 无 Reward；601 次模型生成返回、68 次成功教师短评；8 个 Provider 用量/费用未知记录。记录的 cached input=5,572,672 tokens，66 条记录缺读取量；560 次消息前缀连续不等于 cache hit，也不证明物理跨模型共享。模型已知参考费 $1.42361320 + 教师 $0.03338952 = $1.45700272；**供应商实收、Router/工具/CPU/GPU/VM 的全部 USD 未测**。见[原批次结果](../../our-project/results/iterations/20261108-v9-k3-training/review.md)。

## 5. RQ 图表与历史数据不可混用

- `results/benchmark/rq1/rq1_summary.json`：早期跨策略 106 Episode 的历史表，含不同身份/旧设置；**不能直接作为当前新 GLM K=3 结果**。
- `results/benchmark/rq3/rq3_summary.json`：历史 G0–G3 多 Agent 粒度设置及示例数值；当前项目正式为 **Single-Agent**，不作为最新真实 RQ3 效果。
- `results/benchmarks/rq2_data.json`、`rq4_data.json`、`rq5_data.json` 及其历史图若为合成/预填，只作为演示；实际与否按 [results 总览](../../our-project/results/README.md) 分类。
- RQ1 正式任务净收益仍未闭环；RQ2 真正各档可用性、RQ3 真实子任务边界、RQ4 训练/教师可归因效果、RQ5 独立工作负载边界均存在待证问题。K=3/5/7 是拟研究范围，**不是已测三个池的成绩**。
