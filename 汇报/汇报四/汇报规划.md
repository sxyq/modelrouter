# 汇报四 · 16页正式制作分镜（素材版）
> 2026-11-08，基准：真实 Agent/Provider/训练报告以及两篇核心论文。**这是制作大纲，未生成完整 16 页 HTML 演示稿。** 原仓中的“汇报三 第二个版本”为唯一版式参考；不继承旧多Agent方法或假概率。未完成的论文截图保持待补，不得替换为 AI 假造原图。

## 0. 整套规则

- **内容顺序：P01–P05 真实实测（5 页）；P06–P11 重点论文（两篇各3页）；P12–P14 两篇补充论文（各1页）+ 二者对照（1页）；P15–P16 六套互不依赖的论文调整备选（各三张卡）。**
- **没有封面、过渡、致谢、结论空白页**，P01直接开始研究数据，P16停在六种方案的具体选择点。
- **参考实际页面**：`汇报/汇报三 第二个版本/slides/P03.png`（三卡）、`P11.png`（两组大数与数据模块），`shots/deck-P17.png`（真实比较四区）、`interactive/P06.html`（分步流程）。
- **色彩仅沿用汇报三第二版**：纸白 `#FEFDF9`、卡白 `#FFFEFA`、墨色 `#2A2A24`、青绿 `#24817A`、灰 `#6E6A63`、线 `#E3DCCC`。辅色只在成功/失败、Laya/Kev、引用论文时用赭红 `#B9614A` 与金色 `#C19A57`。不使用大面积渐变及装饰噪声。
- **画布**：16:9，1920×1080。页眉：左上 `P01`（编号/金色短线）+ 主标题（约58–66px）+ 可选一行副标题（约26px）；右上仅简短的分区名，如 `实测进展` 或 `相关研究`。顶部总高度约175px，正文从约210px开始。
- **页脚**：仅右下标准页码 `01 / 16` 到 `16 / 16`，其余底部不出现任何说明性句子、品牌、结论条或引文小字。来源、定义与口径存 HTML 隐藏 speaker notes/单独资料页；图内必要的单位、坐标轴、来源短标签算图表组成，不占页脚。
- **文字密度**：每页一个中心句；普通页面可见中文说明以 **45–90 字**为宜（不含数据标签、论文原图自带文字），顶多 3 个并列主区域；图表数据页可以有8行结果但不添加长段；论文页原始图占45–65%画幅，中文解释以2–3条短句为宜。主体字不小于27px，少数表格标签可用22–24px。
- **精确度**：数字、论文流程和实验结果使用 HTML/SVG 或真正作者原图；GPT 图片只用于不承载事实的抽象背景（本套无必要新生图），不使 AI 复刻论文 Figure、数字或表格。缺 Reward 不绘成失败，历史不同模型池不合算当前 Pass 率；Provider Prompt Cache 不等于跨模型物理 KV。
- **后续输出**：图片、论文笔记、真实统计、HTML 都在 `汇报/汇报四/`；沿用旧播放器的目录/左右切换/全屏功能，不另建前端工程；图片静态为主，数据表及切换对照可局部交互。
