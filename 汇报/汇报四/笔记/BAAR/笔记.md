# BAAR：面向长程 Agent 的边界引导预算路由

> Caiqi Zhang, Menglin Xia, Xuchao Zhang, Daniel Madrigal, Ankur Mallick, Samuel Kessler, Victor Rühle, Saravan Rajmohan；2026-02-04 arXiv v1。完整 PDF 在本仓 `our-project/external/research/papers/09_Budget-Aware_Agentic_Routing_via_Boundary-Guided_Training.pdf`，此次直接复用，不重复归档。

## 0. 一句话定位
把逐步 Strong/Small 二元 Agent 路由当作带长程路径依赖和稀疏终局奖励的预算控制问题；以 Always-Small/Always-Large 两个边界构建任务难度分类，用 BoSFT 合成训练轨迹、BoPO 做边界相关策略优化、硬预算推理时剪除超支动作。

## 1. 研究问题
普通一次性 Query 路由缺乏长程轨迹的早期错误传播与终局反馈。论文分别研究 soft budget 的 Success–Average USD Pareto 和 hard budget 的每任务严格调用预算。两类预算问题不同：前者允许目标函数的成本惩罚，后者要求每条执行轨迹不能违反额度。

## 2. 形式化对象
- 时间 t 的状态 s_t：截至当前已发生的任务输入、工具输出、历史动作。
- 可选动作 a_t∈{M_small, M_large}，论文主实验为 GPT-4.1 mini 和 GPT-4.1。
- 完整执行 τ 的终局成功和各步成本决定优化结果；训练策略以 Qwen2.5-1.5B 生成 SMALL/LARGE 决策 token。
- Soft-budget: E[1(success) − λ·∑c(a_t)]；Hard-budget: max E[success]，满足每条任务 ∑c≤B_max。
- 这些不是 V9 中 K=3 不同 model×native effort 的多类别设置，也不是原生 Effort 调度论文。

## 3. Boundary-Guided Training 主体
### 3.1 任务难度边界
从 Always-Small 和 Always-Large 的表现刻画 Easy、Hard、Intractable：两边都成功为 Easy；强模型成功而弱失败为 Hard；都无法解决为 Intractable。该分类用于训练信号构造，不是在评测时向 Router 泄漏 oracle 标签。

### 3.2 BoSFT
在 Easy/Intractable 任务上尽量利用便宜模型边界，在 Hard 任务上通过分层抽样合成较便宜的强弱模型动作路径，作为 SFT 冷启动。关键是用边界任务轨迹寻找可训练的效率代理，而不是使用单一最终成败直接给每一步生成“最优动作”。

### 3.3 BoPO
普通稀疏奖励 RL 容易退化到只选便宜模型。BoPO 引入相对于边界的奖励与 reference-guided advantage：使采样轨迹不仅比较同组平均值，也比较冷启动参考路径，减少错误的 cheap-failure 解。

### 3.4 硬预算推理
Budget-Constrained Decoding 根据剩余预算过滤可能超额的动作，训练仍以软预算目标为主；作者明确指出固定 λ 的策略对不同硬预算的适配并不完全充分。

## 4. 实验设计
三种任务：SciWorld（科学探索）、ALFWorld（具身指令）、AppWorld（应用 API / 工具编程）。论文训练/测试/最大步数分别：ALFWorld 2420/200/30；SciWorld 2120/200/40；AppWorld 105/168/40。小/大模型为 GPT-4.1 mini / GPT-4.1，定价用提交时的 API 价目表；主要指标为 benchmark 的各自成功定义和每任务平均模型调用费。
**重要口径**：SciWorld 为连续进展分，AppWorld 为 TGC，ALFWorld 为二元成功，不能把所有“Success Rate”字面理解为完全相同的 reward；论文附录明确主 Pareto 图不包括 Router 本身成本（作者另行估计开销）。

## 5. 论文真实结果与边界
- 论文 Figure 1 报告在三个环境的成功—平均成本 Pareto 上 BoPO 优于其比较的普通 RL/单轮/级联基线；ALFWorld 上作者称在约 $0.125 成本达到 >63% 的高表现区。
- Table 1 对最大大模型调用数 K=5、10、15 的硬预算结果进行比较，BoPO 有优势但 **First-Large** 等简单策略有些设置下相当强。
- Figure 2 的组件消融表明剔除分层抽样或参考优势会损害性能。
- 固定 λ 在不同 K 下可能过保守或过度用强模型；这正是作者承认的适用边界。
- 原文实际模型价格不代表我们的 Luna/Terra/GLM 当前 Provider 价格。

## 6. 与 Jev、Whose 和 V9 的差异
对 V9 最直接的竞争不是缓存，也不是“模型池 K 大小”，而是**长程稀疏终局信号也可以训练出逐步 Agent 模型选择策略**。所以“提出任务终局监督”不应独立主张首创。V9 若研究状态、原生 Effort、回本成本或监督可靠性，需要具体可测的额外机制，不能仅改名为 Episode Value。Jev 已做离散委派与 Strong/Fast，Whose 已做有状态 Prompt Cache，BAAR 又覆盖部分训练问题；这三篇的贡献不能互相拼接成假想统一竞品。
