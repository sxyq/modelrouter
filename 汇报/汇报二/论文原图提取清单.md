## 6. 使用边界（PPT 制作时必须遵守）

1. **INFRAMIND 与 Route-to-Reason 的 "reasoning strategy"（Flash/Concise/DeepThink、CoT/PAL/COD 等）是论文自定义策略，不等同于 Provider 原生 `reasoning_effort` 档位**，不得在 PPT 中画等号。
2. **Unified AI Gateway 的跨模型 KV 映射（Cross-Model Mapping）是论文提出的系统级设计与解析仿真结果，不能表述为我们已实现的能力**；本项目当前与之的关系仅为"相关系统级方案对照"。
3. 三张新增图中的数字（如 970 rows / 520 instances、各队列深度）均为**论文实验结果**，不代表本地调用数据实测。
4. TwinRouterBench 是**评测基准**而非路由方法；ProgRouter 是**多 Agent 工作流编排**，与本项目"任务级整轨迹成本的事前预测"定位不同，PPT 中须按差异表述。
