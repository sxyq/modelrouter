# 另一台电脑：拉取并运行「汇报三 · 第二个版本」

> 把下面整段提示词原样贴给那台电脑上的 Agent（或自己照着执行即可）。

---

## 提示词正文（复制这一块）

你在一台新电脑上，需要把「ModelRouter 汇报三 · 第二个版本」这个网页演示拉下来并跑起来。请严格按下面步骤执行，每步做完汇报结果。

### 0. 环境要求

- Python 3.8 及以上（只用标准库，**不需要 pip 安装任何包**）
- Chrome 或 Edge 浏览器
- 能访问 `https://github.com/sxyq/modelrouter.git`

### 1. 拉取代码

```bash
git clone https://github.com/sxyq/modelrouter.git
cd modelrouter
git checkout main
git pull
```

如果已经 clone 过，只需在仓库根目录执行 `git pull`。

### 2. 进入目录并构建播放器

注意目录名里有空格，命令里要加引号：

```bash
cd "汇报/汇报三 第二个版本"
python scripts/deck.py build .
```

构建成功后应看到类似输出：`完成：.../dist/deck.html；已到位 19/19 页`。

> 仓库里已经带了一份 `dist/deck.html`，所以这一步只是刷新用；想直接看也可以跳过，进第 3 步。

### 3. 打开并验收静态部分

用 Chrome/Edge 打开 `dist/deck.html`（双击即可，不需要起本地服务）。检查：

- 共 **19 页**，底部计数从 `01 / 19` 到 `19 / 19`；中间会跳过 P15，显示成 `15 / 19 · P16` 这种形式，这是故意的（P16–P20 的图内印着原页码）
- 第 6 页「Laya 架构原理」、第 7 页「Kev 架构原理」：左下角有「上一步 / 下一步 / 自动播放 / 重置」，键盘 `←` `→` 也能一步步走；第 2 步应能看到 Transformer 层一条一条点亮、注意力弧线逐条扫过
- 快捷键：`←` `→` 翻页，`F` 全屏，`H` 隐藏周边导航，右上角「目录」跳页

到这为止，如果不做真实推理演示，已经可以拿去讲了。

### 4.（可选）启用 P16 / P17 真实双模型推理

这两页要出真实数值，需要本机起一个桥接服务，并且**能连通 A6000 的内网地址**。

**4.1 写上游配置**（含内网信息，Git 里没有，必须自己建）：

在 `汇报/汇报三 第二个版本/assets/` 下新建 `local_config.json`：

```json
{ "upstream": "http://<A6000的内网地址>:8000" }
```

**4.2 起服务**：

```bash
cd "汇报/汇报三 第二个版本"
python assets/bridge_server.py --port 8775
```

**4.3 验证服务**（另开一个终端）：

```bash
curl http://127.0.0.1:8775/api/config
curl http://127.0.0.1:8775/api/health
```

`/api/config` 应返回你刚写的 upstream；`/api/health` 应返回 `"status": "healthy"` 且 `models_loaded` 里 laya、kev 都是 true。

**4.4 回浏览器验收**：刷新 `dist/deck.html`，翻到 P16，头部应显示「A6000 在线」；点「运行 Laya」或「双模型对比」，两侧应出现真实的选择/评分/判断结果，P17 自动读同一轮做对比。

### 5. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| P16/P17 显示「演示服务未启动」或「尚未推理」 | 桥接没起，或起错了端口。确认第 4.2 步在跑，且端口是 8775。这是**正常的降级**，不会出现假数据 |
| 点运行后报 `NETWORK_UNREACHABLE` / `Failed to fetch` | 本机连不上 A6000：检查是否在同一局域网/VPN，`local_config.json` 的地址是否正确 |
| `git pull` 报 `CONNECT tunnel failed, response 502` | 代理问题，多重试两三次即可 |
| 端口 8775 被占用 | 换一个端口：`python assets/bridge_server.py --port 8780`，然后打开 `interactive/P16.html?api=http://127.0.0.1:8780/api`（注意：播放器内嵌版吃不到 `?api=` 参数，这种情况要单独开 P16/P17 页面） |
| A6000 正在训练，点运行要等十几秒 | 正常，单次推理约 10–15 秒；期间不要反复点 |

### 6. 不要提交的东西

`assets/local_config.json`（内网地址）和 `runs/`（每轮原始响应）已在 `.gitignore` 里，**不要手动 `git add -f`**。如果想保存某轮结果，本地留着就行。
