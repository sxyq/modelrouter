📖 核心指标通俗解读词典与工程导向指南 (Field Metric Glossary)
详细解释看板内出现的每一个数字和字段：它有什么用、怎么看、越大越好还是越小越好、基准参考线是多少。
1. S1 Accuracy (最优路由准确率) ⬆️ 越大越好

作用：衡量路由网关在多个专家模型候选中，精准为用户 Prompt 选出“最优回答模型”的命中率。

怎么看：未微调基线为 47.59%，单层基准 64.44%，当前最优达 68.63%。高出基准越多，代表能帮业务省下调用最贵模型的开销。
2. Loss (交叉熵损失函数值) ⬇️ 越小越好

作用：反映模型输出概率分布与真实标注偏好之间的交叉熵误差，衡量网络拟合好坏的核心指标。

怎么看：从初始 1.47 稳定平滑下降到 0.50~0.65 说明训练正常收敛；突增可能代表梯度爆炸或数据破坏。
3. Brier Score (概率校准方差) ⬇️ 越小越好

作用：专门惩罚“盲目自信但选错”的恶劣情况。计算公式为均方误差 1/N * Σ(p_i - y_i)^2。

怎么看：取值在 0~1 之间，越接近 0 代表置信度越可信。未微调基线 0.9021，当前模型已降至 0.4128。
4. ECE (期望校准误差) ⬇️ 越小越好

作用：将模型输出置信度切分为 10 个区间，计算各区间内“平均自信度”与“实际答对率”的绝对差值。

怎么看：小于 0.08 代表校准极佳。未微调基线 0.4402，当前微调后降至 0.0521。
5. Consumed Items (微批样本消费量) ⬆️ 越充分越好

作用：记录优化器反向传播过程中真实“看”过并计算梯度的样本总条数。

怎么看：消除旧版 min_factor 丢弃后，F01~F04 真实消费量应随层数阶梯倍增，L4 达到 382 万条。
6. Distinct Units (独立去重任务单元) ⬆️ 越多样越好

作用：剔除重复生成的 Prompt 后的纯净任务问题总数，反映训练数据的真实语义多样性。

怎么看：数字越大代表见过的题型越广，L1 为 3.2W，L4 扩增至 41.2W 个去重任务。
7. Primary Score (综合天梯选拔总分) ⬆️ 越大越好

作用：加权整合 S1 准确率、Loss、Brier 校准分的多目标天梯分，用于双池晋级自动裁决。

怎么看：基准分为 100 分，当前冠军模型 P0_B03_C01 达 159.25 分。超过 155 分具备晋级核心资格。
8. S2 Agent Score (智能体质量评分准确率) ⬆️ 越大越好

作用：预估多步骤自主智能体工具调用轨迹是否会成功的判决命中率。

怎么看：多数类基线为 50.0%，三任务联合后提升至 54.30%，有效指导高风险任务分流。
9. S3 Cache Accuracy (资源与前缀缓存预测率) ⬆️ 越大越好

作用：预估用户请求将消耗的 Token 长度范围与 KV 缓存前缀命中层级的能力。

怎么看：初始准确率仅 30.1%，消融协同后大幅提升至 43.74%，有效防止长文本推理成本失控。
10. GPU Util & Power (算力利用率与功耗) 🎯 85%~98% 满载

作用：反映 RTX A6000 48GB 显卡计算单元是否处于高效运转状态，避免 CPU 数据瓶颈。

怎么看：保持在 75%~95% 且功耗接近 280~300W 额定上限为最优状态；低于 50% 说明数据加载发生卡顿。
11. VRAM (显存使用量与峰值) ⬇️ 安全稳定为佳

作用：模型权重、KV 缓存及反向传播梯度占用的显存大小。

怎么看：保持在 10,000~15,000 MiB（占 49,140 MiB 的 20%~30%），留出大批余量，杜绝 OOM 爆显存风险。
12. Dual Pool Retention (双池留存机制) 🎯 稳态 18.9 GiB

作用：旧池锁定 5 份基准核心物理权重不被误删；新池对达标新候选按 15% 动态择优入驻。

怎么看：淘汰率 96.1%，相比传统无脑存权重的 354 GiB 节省 94.6% 空间，兼顾演化与磁盘安全。
