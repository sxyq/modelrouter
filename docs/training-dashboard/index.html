📖 核心指标通俗解读词典 (Glossary & Metric Guide)
每个字段的作用、查看方法与优劣导向（越大越好 ⬆️ 或越小越好 ⬇️）：
1. S1 Accuracy (路由准确率) ⬆️ 越大越好

作用：衡量在多个候选模型中选对最优回答模型的概率。

怎么看：基准为 64.4%，当前达 68.6%，高出基线越多代表路由分流价值越高。
2. Loss (损失函数值) ⬇️ 越小越好

作用：反映模型输出概率与真实偏好标签的交叉熵误差。

怎么看：从 1.47 稳定下降到 0.61~0.70 说明训练正常收敛，数值越小越精确。
3. Brier Score (校准偏差) ⬇️ 越小越好

作用：惩罚“盲目自信但判断做错”的情况，评估置信度质量。

怎么看：取值在 0~1 之间，越接近 0 越好，当前最优为 0.4128。
4. Primary Score (天梯综合分) ⬆️ 越大越好

作用：加权整合 Loss、Accuracy 和校准度的综合质量天梯分。

怎么看：基准为 100 分，当前最高分达 159.25 分，越高越具备晋级资格。
5. S2 智能体质量评分准确率 ⬆️ 越大越好

作用：对智能体调用工具与决策轨迹成败的预估命中率。

怎么看：突破多数类基线后达 54.30%，有效指导高风险任务的分流。
6. S3 资源缓存预测准确率 ⬆️ 越大越好

作用：预估请求所需 Token 长度与 KV 缓存复用层级的能力。

怎么看：从 30.1% 跃升至 43.74%，越高越能避免推理成本失控。
