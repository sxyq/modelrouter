2. 官方如何制作与训练

公开学术与 GitHub 侧能确认的是「有 RLCD」；不能确认的是「怎么训出来的」。

结论：无法从公开学术源复现官方 Jev。 若目标是「训一个 Jev-like 决策模型」，应改走社区开源栈（见下节），而不是等待官方训练细节。
厂商叙述（需谨慎）
TypeSafe 博客称使用 RLCD + 新架构 + 并行采样器；强调面向校准概率，而非偏好文本 RLHF。创始人口径：架构先保密，重点在数据。

3. 如何自训一个 Jev-like 模型

公开可复现路径对比。许可与数字以各仓库/论文为准，社区自报数字未在本机全部复测。

自训参考配方（以 Visual Jev 为例）

训练配置

项值
BackboneQwen3-VL-4B-Instruct（bf16）
适配语言塔 LoRA r=16, α=32, dropout 0.05
数据GQA Choice 30,416 + SNLI-VE 9,000
目标Answer SFT（候选字母 token 交叉熵）
步数/batch3,000 / 8
优化器AdamW + cosine · LR 1e-4 · warmup 100
硬件1× RTX 5090 · 约 45 min · 峰值 ~14.4 GiB
结果宏平均 0.706 → 0.761（增益偏训练任务类型）

Kev / Laya / RFDT 要点

路径关键能力
Kev公开权重 kev-0.8B~27B；kev.train；可自托管 /v1/systemone；Apache-2.0
Laya开放权重 + Kaggle 微调笔记本；typed-decisions 声称 0.362→0.766；置信度公式与 Jev 不同

AnyJev零/少标签校准；vLLM embed 服务；作者声明与 TypeSafe 无隶属

4. 能否用在 ModelRouter

本项目关注长程 Agent 的模型、推理档位与任务级成本。Jev 与该问题高度贴合。

适配点

  • 事前配置选择器：state = episode 特征，Choice 选「模型 × effort」
  • 质量守卫：Noul 问「该配置在约束下是否够用」
  • 成本控制：Score 标出风险分位，再决定是否升级档位
  • 数据回流：Jev 打标 → 训练本地路由头（注意标签误差）
  • 对照实验：托管 Jev / 本地 Kev·Laya / 纯启发式路由器

不建议的做法

  • 把 Jev 当任务执行编码模型
  • 直接照搬首页倍数做成本承诺
  • 跨实现共用同一置信度阈值
  • 高风险不可逆动作只靠高置信概率放行
  • 跳过自有数据评估就上生产路由

5. 如何放入 Codex 使用

官方明确：Jev 不能写成 Codex 的 coder model_provider。可落地的是旁路决策。

实测参考（掘金，2026-09-23）： 安装官方 skill 后，任务由 Jev Choice 决定下一步，confidence ≥ 0.8 才执行；可见 model: jev-1.13.0，choice=web_search，confidence=0.99。 反例：CSDN 大量把 Jev 写成 Codex 聊天后端的模板文，定位错误，不宜照抄。
OpenRouter 中转
Decisions API 与 System One API 仍按 decision 形状调用；不要把 questions 塞进 chat-completions。
可用
真·自定义 coder
另配 model_providers + Responses 兼容上游（vLLM/代理）。与 Jev 决策是两条线。
独立
LLM 模拟 System One
官方 system-one-adapter-python 可用 OpenAI/Anthropic 等模拟接口，便于无 TypeSafe 账号时先跑通。

7. 风险与批评

以下为独立研究与社区复测意见，与官方营销数字分开展示。

性能叙述 vs 独立观察

厂商 launch 叙述（加速倍数）20–200× / 首页 193×
用户自述中位（OpenChamber）约 7× 加速 / 约 30× 成本
独立测试（vs Mistral Small 4）约 5× 加速 / 约 8.6× 成本

条形仅示意量级差，非精确坐标图。使用前务必用自有负载重测。

校准与可靠性（定性）

顺序偏置
只改选项名/极性绑定即可大幅拉低 AUC；AnyJev/Visual Jev 等路线强调轮换或规范化读出。
校准漂移
高置信错误仍会发生；第三方审计显示阈值上的误差不理想；实现间 confidence 公式不同。
注入
类型化输出降低自由发挥，仍可被注入或自然语境翻转决策。
路由收益不确定
有基准显示 Jev 选子代理成本高于单一高 effort 智能体。
准入与信息污染
waitlist 与限流被广泛讨论；内容农场教程常把定位说错。
「零幻觉」措辞要读清楚： 它描述的是输出形状被类型约束，而不是事实永远正确。把 Jev 当校验器时，仍需可回退的证据链与人工抽查。

9. 一页结论

1
Jev 是快速校准的类型化决策层
Choice / Noul / Score + 概率；不是聊天编码模型，也不是公开可训的开放权重产品。
2
官方训练细节不可公开复现
只有 RLCD 名称与 API 行为；要训练请走 Visual Jev / Kev / Laya / RFDT / AnyJev。
3
ModelRouter 高度可用
用作事前配置选择器、守卫与对照节点；用自有账本验证收益，拒绝外推首页倍数。
4
Codex 旁路接入
官方 skill + hooks + 兼容 API；不要把 Jev 填进 model_provider。
5
适用面宽，但阈值与证据要自己扛
路由、审核、批处理、边缘决策均可试；高风险动作必须人工回退。
